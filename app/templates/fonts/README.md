# Document typography

Inter Regular and Bold, matching the invoice PDF family.

Source: https://github.com/rsms/inter/tree/353b61b9f4430d5f420d56605a6e7993e0941470/docs/font-files

The official static WOFF2 files were decoded to TrueType with fontTools for
wkhtmltopdf compatibility, preserving glyphs and font metrics. Licensed under
the SIL Open Font License 1.1; see LICENSE.txt.
